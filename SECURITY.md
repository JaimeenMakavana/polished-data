# Security Policy

## Reporting a vulnerability

Do **not** open a public issue for security problems.

Report privately via GitHub Security Advisories:

https://github.com/JaimeenMakavana/polished-data/security/advisories/new

Include:

- what is affected (docs, agent instructions, example scripts, CI)
- how to reproduce
- impact (data leak, unsafe acquisition advice, secret exposure)

You should hear back within 7 days. We will coordinate a fix before any public disclosure.

## What this project will never do

Agent instructions in `SECURITY_AND_ACCESS.md` are binding:

- no bypassing logins, CAPTCHAs, paywalls, or access controls
- no fabricating records
- no committing secrets

If you find instructions or examples that contradict that, treat it as a vulnerability and report it here.
